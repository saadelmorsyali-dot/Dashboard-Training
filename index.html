MODULE 04 · AI

Use ChatGPT as your development partner

The skill is not asking AI to “make a dashboard.” The skill is giving AI enough context to make the right dashboard.

WEAK
Create a dashboard.
BETTER
I am a beginner. Here is my dataset and the business goal. Design an executive dashboard with KPIs, charts and filters. Explain your decisions before writing code.

The master prompt pattern

ROLE: You are a senior dashboard developer and teacher.
CONTEXT: I am a complete beginner.
DATA: [describe or attach the dataset]
GOAL: [what the dashboard must help users decide]
DESIGN: [preferred style]
CONSTRAINTS: [hosting, libraries, mobile, etc.]
TASK: [one specific thing you want now]

Before coding, explain the approach and list assumptions.
✓ Checkpoint: You can ask AI for one controlled task instead of asking it to build everything blindly.

MODULE 10 · GOOGLE SHEETS

Prepare the live data source

Your sheet remains the place where users update the business data. The dashboard should consume the latest data rather than requiring manual copying.

01

Keep a clean header row

Use consistent column names. Avoid merged cells and decorative rows inside the data table.

02

Keep data types consistent

Dates should be dates, numbers should be numbers, and percentages should follow one convention.

03

Separate data from presentation

Do not rely on cell colors or manual formatting as the source of dashboard logic.

MODULE 11 · APPS SCRIPT

Create the live connection

Apps Script can expose your Google Sheet data through a web-app endpoint. The HTML dashboard can then request the current data.

01SheetSource
→
02Apps ScriptConnector
→
03JSONData response
→
04DashboardDisplay
function doGet() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Projects_Data');
  const values = sheet.getDataRange().getValues();
  const headers = values.shift();
  const data = values.map(row => Object.fromEntries(headers.map((h,i) => [h,row[i]])));
  return ContentService
    .createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}
⚠ Security

Do not put passwords, API keys or confidential information in client-side HTML or public repositories. Use appropriate access controls for real company data.

I have a Google Sheet with one data table named Projects_Data. Create a Google Apps Script web app that returns the rows as JSON. Explain deployment and permissions step by step for a complete beginner. Do not expose secrets in the HTML.
MODULE 12 · BUILD

Connect the HTML dashboard

Once Apps Script gives you a web-app URL, place that URL in the dashboard JavaScript and fetch the live JSON.

const DATA_URL = 'PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE';

async function loadData() {
  const response = await fetch(DATA_URL);
  if (!response.ok) throw new Error('Unable to load dashboard data');
  const data = await response.json();
  renderDashboard(data);
}
✓ Checkpoint: Change a safe value in the Google Sheet, refresh the dashboard, and confirm the dashboard reads the new value.
